💻 Hardware Troubleshooting Basics

Scenario: Computer Won't Turn On
A customer calls saying their desktop computer won't turn on at all. No lights, no fans, nothing happens when they press the power button.

What should be your FIRST troubleshooting step?

Replace the power supply immediately
Check if the power cable is properly connected and the outlet is working
Open the computer case to check internal connections
Ask the customer to buy a new computer
Correct! Always start with the basics - power connections and external factors before diving into internal components. This follows the principle of checking the simplest solutions first.
Check Power Source
Verify power cable connection and test the outlet with another device.
Inspect Power Button
Ensure the power button isn't stuck or damaged.
Check Internal Connections
Open case and verify all power connections are secure.
Test Power Supply
Use multimeter or paperclip test to verify PSU functionality.

💿 Software Troubleshooting

Scenario: Application Crashes
A customer's Microsoft Word keeps crashing every time they try to open a specific document. Other documents work fine.

What's the most likely cause of this specific issue?

The entire Office suite needs to be reinstalled
The specific document file is corrupted
The computer needs more RAM
Windows needs to be updated
Correct! Since other documents work fine, the issue is likely isolated to that specific file being corrupted. This is a common occurrence with document files.
Try Opening in Safe Mode
Hold Ctrl while opening Word to start in safe mode, then try opening the document.
Check File Properties
Right-click the file to check its size and properties for anomalies.
Use Document Recovery
Try Word's built-in "Open and Repair" feature when opening the file.
Restore from Backup
Look for auto-recovery files or previous versions of the document.
